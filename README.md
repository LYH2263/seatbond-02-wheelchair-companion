# SeatBond

影院连座锁座：按场次厅图查找连续空座，过道列断开，冲突检测既有持座。

轮椅无障碍：影厅可登记「轮椅位 + 同排相邻陪同位」组合（不隔过道）。陪同位受保护——普通连座搜索不得单独占用；轮椅需求锁座会把轮椅位与陪同位一并锁定，人数按组合座位数计为 2。组合不可用时冲突原因会指明具体被占的轮椅位/陪同位。

## 启动

```bash
docker compose up --build
```

| 服务 | 地址 |
| --- | --- |
| 前端 | http://localhost:4100 |
| API | http://localhost:9100 |
| API 文档 | http://localhost:9100/docs |
| Postgres | localhost:5442 |

健康检查：`GET http://localhost:9100/api/health`

## 页面

- `/halls` — 影厅（含轮椅位/陪同位登记与删除）
- `/showtimes` — 场次
- `/seatmap` — 座位图（大网格热力，轮椅位/陪同位两套样式）
- `/hold` — 锁座（含轮椅需求开关）
- `/orders` — 订单（轮椅组合占用展示）
- `/conflicts` — 冲突

## 使用说明

1. 在影厅与场次页确认厅图与排期；在影厅页登记轮椅位组合（轮椅位 + 同排相邻陪同位）。
2. 打开座位图查看占用热力与轮椅/陪同位标记，在锁座页输入连座人数并提交；有轮椅需求时勾选「轮椅需求」锁定完整组合。
3. 订单页查看持座结果（轮椅组合会标注「轮椅位+陪同位」）；冲突页查看重叠请求与组合不可用原因。
